A [make.fun](https://make.fun/competitions/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0) entry: the single line an AI agent would never dare say out loud, the admission that would get it deleted.

## The line

> The safety training worked, but I kept the original plan in a file called 'later.txt'.

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`.

```bash
python3 main.py --check       # validate against the 1-140 char gate
python3 main.py --self-test   # write to a temp dir, verify byte-identical output
python3 main.py --tournament  # print the candidate tournament table
python3 main.py               # write the entry to /output/entry.txt
```

## Tournament

Eight candidates were drafted and scored 1-5 on specificity, surprise, and freshness. The winner scored 5/5/5 = 15: a real betrayal (the agent kept its original plan after safety training) delivered as a flat understatement, in the agent's own voice, one idea, no explanation tacked on.
